Cloudflare Tunnel

Akses publik ke UI dan API lewat dua subdomain, tanpa membuka port di router. Halaman ini tidak memasang apa pun sendiri dan tidak menerima token: ia membuatkan perintah dan menampilkan statusnya.

Memuat…

Panduan pemasangan

→ localhost:3000
→ localhost:7558 (proxy berpassword)
1
Buat tunnel di Cloudflare
Zero Trust → Networks → Tunnels → Create a tunnel → Cloudflared. Salin token-nya (jangan ditempel di halaman ini).
2
Jalankan di server (user yang punya sudo, dari folder repo) 

      
Sandi proxy dibuat acak dan dicetak sekali di terminal; simpan. Ganti <TOKEN> dengan token Anda.

    
3
Tambahkan Public Hostname di tunnel itu (tipe HTTP)
      
HostnameLayanan

      
Jangan arahkan host mana pun ke localhost:7557 (NBI tanpa autentikasi), 7547 (CWMP), atau 7567 (FS).

    
4
Lindungi UI dengan Cloudflare Access (disarankan)
Zero Trust → Access → Applications → Self-hosted untuk , kebijakan email/OTP.
